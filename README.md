# بيت الحلو — متجر حلويات متكامل

موقع كامل بالعربية (RTL): واجهة المتجر + سلة + نموذج طلب + لوحة تحكم + باك إند + قاعدة بيانات.
مكتوب بـ **بايثون فقط بدون أي مكتبات خارجية** (يستخدم `http.server` و`sqlite3` الجاهزتين).

## التشغيل على جهازك

المطلوب: Python 3.8 أو أحدث.

```bash
cd sweets
python3 server.py
```

- المتجر: http://localhost:8000
- لوحة التحكم: http://localhost:8000/admin.html (كلمة السر الافتراضية `admin123`)

### تغيير كلمة السر (مهم قبل النشر)

```bash
# لينكس / ماك
ADMIN_PASSWORD="كلمة-سر-قوية" python3 server.py

# ويندوز (PowerShell)
$env:ADMIN_PASSWORD="كلمة-سر-قوية"; python server.py
```

## تعديل بيانات المتجر

افتح `server.py` وعدّل القاموس `STORE` في أعلى الملف:
الاسم، الشعار، العملة، رقم واتساب (بصيغة دولية بدون + مثل `201012345678`)، الهاتف، العنوان، رسوم التوصيل، وحد التوصيل المجاني.

## المزايا

- عرض المنتجات مع فلترة حسب التصنيف
- سلة مشتريات تُحفظ في المتصفح، وحساب التوصيل تلقائياً
- نموذج طلب (الدفع عند الاستلام) يُحفظ في قاعدة البيانات
- لوحة تحكم: إحصائيات، متابعة الطلبات وتغيير حالتها، إضافة وتعديل وحذف وإخفاء المنتجات
- زر واتساب للتواصل

## الأمان

- الأسعار تُحسب دائماً على الخادم من قاعدة البيانات، ولا يمكن للزبون التلاعب بها
- كل الاستعلامات مُهيَّأة (Parameterized) ضد حقن SQL
- عرض البيانات في الصفحات عبر `textContent` فقط ضد XSS
- حد لمحاولات تسجيل الدخول، وجلسات مؤقتة (8 ساعات)
- **انتبه:** الخادم يعمل بـ HTTP عادي. عند النشر العام ضعه خلف HTTPS (تفعله منصات الاستضافة تلقائياً)

## النشر على الإنترنت (رابط عام)

الخادم مثالي لمنصات مثل Render أو Railway أو Fly.io أو VPS عادي:

1. ارفع مجلد المشروع إلى GitHub.
2. أنشئ خدمة Web جديدة على المنصة، وأمر التشغيل: `python3 server.py`
3. أضف متغير البيئة `ADMIN_PASSWORD`.
4. **مهم:** ملف قاعدة البيانات `sweets.db` يجب أن يُحفظ على قرص دائم (Persistent Disk / Volume)، وإلا ستضيع الطلبات عند إعادة التشغيل. اضبط `DB_PATH` على مسار القرص، مثل `/data/sweets.db`.

المنصة تحدد المنفذ تلقائياً عبر متغير `PORT` والخادم يقرؤه.

## هيكل المشروع

```
sweets/
├── server.py          الباك إند + قاعدة البيانات + الـ API
├── sweets.db          تُنشأ تلقائياً عند أول تشغيل (مع منتجات تجريبية)
└── static/
    ├── index.html     صفحة المتجر
    ├── style.css      التصميم
    ├── app.js         منطق المتجر والسلة
    ├── admin.html     لوحة التحكم
    └── admin.js       منطق لوحة التحكم
```
